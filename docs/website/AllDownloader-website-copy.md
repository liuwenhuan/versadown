# AllDownloader：让下载，从一个入口开始

**AllDownloader 是一款本地优先的 Windows 下载客户端。**

把直链、磁力链接、种子、迅雷链接和已授权网盘中的文件，放进同一条清晰的下载流程：识别、确认、开始、管理。无需在多个网页、客户端和临时窗口间来回切换。

> 面向需要“现在就把文件下到电脑里”的人，而不是替代每一家网盘的完整客户端。

## 你会用它来做什么

- 粘贴 HTTP/HTTPS 直链、磁力链接、`.torrent` 或迅雷链接，快速创建下载任务。
- 从复杂文本中识别可下载链接；遇到多文件或需要确认的内容，先让你确认再开始。
- 在一个下载队列里查看进度、暂停、继续、取消和处理失败任务。
- 通过悬浮快捷入口随手粘贴链接，再回到主窗口管理任务。
- 授权后，从支持的网盘中浏览和选择文件，并把文件交给本地下载流程。

AllDownloader 使用 aria2 在本机执行已确认的下载任务；下载速度由文件源、网络环境和服务方规则共同决定。我们不会把“高速”包装成对所有链接都成立的承诺。

## 网盘接入：只做下载前的最后一公里

网盘接入的目标很简单：当文件已经在你的网盘里时，让你少走几步，尽快把它下载到本地。

在服务方允许且你完成本人授权的前提下，AllDownloader 可提供网盘内的文件浏览、选择和下载入口；支持的服务和授权方式以软件当前版本实际显示为准。它不是一个全功能网盘客户端，因此不会试图复刻网盘的全部能力。

如果你需要高速通道、在线解压、AI 编辑、在线预览、协作空间或其他会员增值服务，请在对应网盘的官方网站或官方客户端使用并购买服务。会员权益、限速策略和内容能力属于服务商；AllDownloader 不绕过它们，也不承诺替代它们。

## 该选谁？

没有一个下载工具适合所有人。下面的比较帮助你按需求选择，而不是宣称谁取代谁。

| 产品 | 更适合的场景 | 产品取向 |
| --- | --- | --- |
| **AllDownloader** | Windows 上临时处理多种链接，或从已授权网盘迅速挑选文件并下载到本地 | 统一入口、本地任务流程、轻量网盘下载衔接 |
| **Motrix** | 需要跨平台的标准下载管理，以及深入使用 HTTP、FTP、BT、磁力和 Metalink | 完整下载管理器，提供任务控制、浏览器衔接与插件工作流 |
| **迅雷** | 需要官方会员提速、网盘生态或多端服务 | 商业化下载和存储服务，会员权益与生态能力由官方提供 |

AllDownloader 的重点不是比 Motrix 多一套完整下载器功能，也不是取代迅雷的会员服务；它希望成为更快抵达“开始下载”这一步的入口。第三方产品能力会持续变化，请以其官方说明为准：[Motrix](https://motrix.app/features/) · [迅雷](https://www.xunlei.com/download/)。

## 本地优先，也尊重边界

- 下载任务和状态保存在本机，恢复后仍可继续管理。
- 网盘授权由用户本人完成；凭据和短时下载地址不会被写进任务来源或调试信息。
- 不共享账号、Cookie、token、下载能力或解压密码。
- 不绕过验证码、短信验证、扫码验证、DRM、付费内容、会员限制或服务方的授权流程。
- 当服务方不允许内嵌授权时，会转到官方允许的网页或系统流程。
