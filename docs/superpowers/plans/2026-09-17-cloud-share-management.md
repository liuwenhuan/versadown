# 各网盘分享管理实现计划

1. 新增共享层 DTO、`ShareOps`、能力字段和 provider driver 转发方法；先写契约与能力门控测试。
2. 在各原生 provider driver / client 中实现创建、列举、取消分享的协议适配，并在命令层提供 Tauri 调用和“我的分享”虚拟目录投影。
3. 扩展前端云盘类型与 API client，加入分享命令。
4. 用分享对话框替换文件详情：移除详情组件和样式，在右键/多选菜单接入分享，创建成功后提供复制链接。
5. 在根目录注入“我的分享”，实现其中的分享链接复制与取消分享上下文菜单。
6. 执行 CloudManager 定向 Vitest、相关 Rust 测试、前端构建和 Windows 发布构建；根据实际失败做最小修复后提交并合并。
