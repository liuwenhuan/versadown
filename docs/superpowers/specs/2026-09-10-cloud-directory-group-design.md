# 云盘目录下载任务组设计

## 目标

用户从任一已接入网盘选择一个目录下载时，下载队列在任一标签页只显示一个可持久化的目录父任务。父任务可以展开为与网盘目录相同的递归目录树，显示每个文件的实际传输进度、状态和错误；它不会把目录中的文件平铺为多个顶层任务。

## 范围和约束

- 覆盖夸克、PikPak、百度、天翼、阿里、迅雷和 UC 的 `cloud_download_directory` 流程；连接器仍然只负责列目录和为单个文件取直链。
- 保留现有每个文件一个 aria2/本地 `tasks` 记录的传输模型。目录父任务是任务组投影，不会把不兼容的多文件传输伪装成一条 aria2 任务。
- 保留现有 BT/磁力多文件选择、单文件下载、分享转存清理和重复下载语义。
- 父任务及其项目关系必须写入 SQLite；应用重启、列表轮询和任务状态变更后仍可恢复同一树。
- 目录遍历在任何文件入队前完成，继续沿用现有的循环、重复节点、空目录、路径冲突和数量上限校验。
- 不在组表中保存登录凭据或短效直链；只保存网盘提供方、稳定文件 ID、经过输出安全检查的相对路径、输出文件名和本地子任务 ID。

## 数据模型

新增 `cloud_directory_groups` 表，由 UUID 主键、提供方、根目录 ID、显示名称、目标根目录、创建/更新时间组成。新增 `cloud_directory_group_items` 表，每一行对应完整遍历结果中的一个文件，保存：组 ID、稳定序号、远端文件 ID、相对目录组件、输出名、已验证的目标路径、本地子任务 UUID（可为空）、入队失败码和用户可见失败信息。

`PlannedCloudFile` 补充已知长度（若连接器列目录未提供则为空），使尚未入队或入队失败的叶子也能被父任务正确统计。每个目录选择无论包含多少文件只创建一个组；一次选择多个目录时，每个被选目录创建一个组。

本地子任务仍由既有 `tasks` / `task_files` 表拥有其实际状态、aria2 GID、进度、重试和清理记录。一个目录组项目要么链接一个本地任务，要么保留其可重试的远端文件描述和失败状态；不会通过名称猜测或扫描下载目录关联任务。

## 下载和状态投影

`cloud_download_directory` 先生成完整计划、原子创建父组和项目行，再逐个提交文件。成功入队后写入对应本地任务 UUID；提交失败则写入该叶子的失败原因。这样即使部分直链或引擎提交失败，用户仍可在同一个父任务内看到完整文件清单和失败位置。

列表命令会排除已被目录组链接的本地子任务，并改为返回一个合成的 `folder` 队列任务。合成任务带有递归 `children`：目录节点按相对路径建立，叶子读取链接本地任务的实时信息；未提交叶子显示已记录失败。根节点的总长度、完成长度、速度、连接数和 ETA 由叶子聚合；未知长度不伪造为零。

若任一叶子仍处于草稿、排队、下载、暂停或处理中，父任务显示在“下载中”。只有所有可下载叶子成功完成且没有失败叶子时才进入“已完成”；存在失败叶子且没有活动叶子时显示“失败”。取消、回收和清除遵循同样的全体聚合规则，避免一个目录同时出现在不相容的标签页。

## 交互

下载队列将现有 BT 的单层子文件展示替换为可递归的树形渲染，保持 BT 文件选择控件原有行为。云盘目录父行和目录节点均有展开/收起控件；叶子展示单文件进度、大小、状态、错误和可用操作。展开状态只保存在前端视图状态，重启后默认收起，不影响下载。

父任务的暂停、继续、取消、重试、移入回收站、彻底删除和打开目录会以确定的方式作用于其可操作叶子：暂停/继续处理活动叶子，取消处理未终止叶子，重试处理失败叶子，回收/清除处理组内本地任务及可安全删除的输出文件。目录节点只控制其后代。操作结果汇总为一条组级反馈，单个叶子失败仍显示在树中。

## 错误和恢复

计划阶段错误不创建任务组也不入队任何文件。计划完成后的单文件错误不丢失目录父任务：错误以叶子形式持久化，父任务显示部分成功与失败数量。重试会只重新提交未关联本地任务的失败叶子，并仍使用保存的提供方/远端文件 ID/安全输出路径；已经有本地任务的叶子不重复提交。

若旧版本已有平铺的云盘目录子任务，它们不会被猜测性迁移或隐藏，避免把无关同名文件归组；新版本开始的目录下载才使用任务组。

## 测试与验收

- Rust：目录计划包含嵌套路径和长度；创建组、部分提交失败、重启后投影、状态聚合、组级命令目标和旧平铺任务兼容。
- TypeScript：一个目录只渲染一个顶层父行；多层展开准确显示子目录/文件；活动/失败/完成叶子聚合正确；BT 多文件控件保持可用。
- 集成：通过 Tauri 的目录下载命令验证一次嵌套目录选择生成一个父任务及其叶子，不暴露链接子任务为顶层项。
- 验收：选择包含任意数量文件和子目录的云盘目录后，所有下载进度可从一个父任务逐层查看；完成或失败不会产生平铺顶层文件任务。
