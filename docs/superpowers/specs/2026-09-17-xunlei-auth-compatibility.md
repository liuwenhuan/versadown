# 迅雷授权兼容与账号密码登录设计

> 已废弃：用户要求彻底重写登录授权，此旧桥接方案不再实现或维护。现行方案见 `2026-09-17-xunlei-auth-plugin-rewrite.md`。

## 目标

- 兼容迅雷云盘网页 `1.92.101`，授权成功且根目录验证通过后自动关闭授权窗口并生成网盘菜单。
- 尽量不依赖 webpack 模块编号，降低后续官方网页升级造成的维护频率。
- 后续网页结构确实不兼容时，停止无限等待并显示包含网页版本的明确错误。
- 在迅雷网盘卡片中提供账号密码入口，密码只注入迅雷官方 HTTPS 页面并按现有规则加密保存在本机。

## 设计

网页桥接只遍历 webpack 已加载模块的导出，不执行未知模块工厂。它按公开客户端配置识别 profile，按导出能力识别 SSO、OAuth、设备对象和 profile 指定的签名函数；旧版模块编号仅作为兼容回退。已登录且官方版本可见、但必要导出仍无法识别时，返回固定错误代码和经过限制的版本字符串，由 Rust 转换为明确中文错误。

账号密码登录复用现有官方 WebView 表单注入。Xunlei 声明精确受信任域名和持久化浏览器配置；登录完成后仍通过同一个网页令牌桥接和根目录请求验证，只有验证成功才保存会话与加密密码，并将账号认证方式标记为 `password`。

## 约束

- 不记录或输出账号、密码、令牌、Cookie、DOM 或存储转储。
- 不绕过验证码；需要人工验证时显示官方窗口。
- 不为阿里云盘、UC 等尚未实现的 `officialWebView` 登录误开放密码入口。
- 保留 1.92.98、1.92.100 兼容测试。
