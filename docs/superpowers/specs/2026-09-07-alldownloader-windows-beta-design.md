# VersaDown Windows Beta 设计规范

## 目标与边界

VersaDown 是优先面向 Windows 的本地下载客户端。用户粘贴直链、磁力/BT、迅雷链接、网盘分享链接、文本或网页地址；应用选择确定性规则或受限的 AI 辅助，形成可审阅的下载任务，然后用本地下载引擎执行。首版还提供用户自己的夸克与 PikPak 网盘的文件目录浏览和基础管理界面。

本 Beta 不包含用户间账号、下载能力、Cookie、直链或凭据分享；不绕过验证码、风控、DRM、付费内容或密码；不自动执行下载内容中的程序、脚本或宏。虚拟积分与回复可见动作只可在用户将任务交给应用并启用对应站点规则后执行；积分不足即失败并提示。

## 交付形态

- Windows：Tauri 2、React/TypeScript 界面、Rust 本地核心。
- WebView2 只承载可见的登录、验证、回复和服务商允许的授权；外部页面放在隔离窗口中，不能访问文件系统、下载核心或凭据库。
- 解析、任务数据库、凭据库、aria2 RPC、后处理和连接器全部在设备本地运行。
- 在线安装包预期 25–50 MB；安装后常见 50–110 MB。离线 WebView2 安装模式额外增加约 127–180 MB。

## 核心流程

1. 浮动 48×48 启动器接收粘贴；单击展开 470×300 输入面板，主按钮为“开始解析下载”。
2. 分类器优先识别 HTTP/HTTPS、magnet、`.torrent`、Thunder、夸克与 PikPak 分享链接。标准单文件解析完成后立即创建下载任务；多文件、种子或目录打开选择窗口。
3. 文本、网页、附件清单或明显混淆的内容先由本地提取器获得候选链接；只有仍不能可靠理解时才把当前任务的脱敏可读文本发送给云端 AI。AI 只能返回结构化候选资源、密码提示和处理建议，本地策略引擎必须验证后才能执行。
4. 多文件确认窗口显示可选择的文件树、大小、保存目录，以及折叠的后处理和密码摘要。页面/文本中确定匹配的密码可自动使用；未知密码使任务等待用户输入。
5. 下载任务在 aria2 中执行，实时同步到主下载管理器。目录在列表中是一条父任务；展开后显示子文件进度，并允许暂停、继续和取消单个子项。
6. 新下载的文本、种子、压缩包清单在策略允许时回流到提取阶段，无需重复确认。后处理仅允许解压、分卷合并、改名、校验等白名单操作。

## 模块与接口

### 1. 桌面壳与界面

- `floating launcher`：显示整体进度环、错误点和队列数；输入展开后可以粘贴内容或调用系统剪贴板。
- `download manager`：左侧导航（下载、网盘、设置），中间队列，右侧所选任务详情。父任务将子项的状态、速度、已完成和错误聚合。
- `parse confirmation`：只对多个可下载资源/目录展示；支持勾选/反选、保存路径和后处理摘要。
- `cloud manager`：首版对夸克/PikPak 使用应用自绘文件树，不复用其官方网站 UI；支持目录导航、创建目录、改名、移动、删除、上传与加入下载。删除必须有确认框。

### 2. Rust 本地核心

- `TaskService`：任务图、状态迁移、持久化、取消传播、错误归类、恢复。
- `ParserService`：确定性模式匹配、网页可读文本提取、种子/目录规范化、AI 调用编排。
- `PolicyService`：执行前验证资源来源、域、步骤与后处理白名单；拒绝 AI 的任意命令或路径。
- `DownloadService`：管理 aria2 sidecar JSON-RPC、进度轮询、分组下载与失败重试。
- `ProcessingService`：在任务专属工作目录执行有限、可记录的处理步骤；不启动未受信任可执行文件。
- `CredentialService`：通过 Windows DPAPI/凭据库保护用户输入的账户密码；Cookie 和站点存储留在各自 WebView2 用户数据目录。日志从不记录密码、Cookie、token 或完整受保护 URL。

### 3. 连接器

统一接口：`connect`、`checkSession`、`parseShare`、`listDirectory`、`download`、`upload`、`createDirectory`、`rename`、`move`、`delete`。能力由连接器显式声明。

夸克和 PikPak 是 Windows Beta 的实际连接器目标。连接器只能使用用户授权会话、正式 API 或经验证的开源实现提供的可见用户能力；遇到服务商改版、权限不足或不可用接口时，任务要给出可操作错误，绝不伪造成功或绕过限制。若内嵌 WebView2 被 OAuth 拒绝，改用系统浏览器或服务商允许的流程，绝不抓取 token。

### 4. 浏览与自动化边界

- 任何网站成功登录后，应用保存本机受保护的会话并在过期前复用。
- 短信、扫码、验证码、动态文本和未知表单一律暂停并呈现给用户处理。
- 已配置的“回复可见”站点规则限定固定站点、固定文字、最大次数，并记录动作；不可泛化为未知页面自动发帖。
- 虚拟积分操作使用任务提交即同意的语义；余额不足则报错，不做预算或积分审计。

## 数据模型

- `Task`：ID、输入、类型、状态、输出目录、父任务、进度、总量、速度、错误码、创建/更新时间。
- `Resource`：任务 ID、来源、原始/规范化地址、文件名、大小、hash、选择状态、敏感字段引用。
- `ProcessStep`：任务 ID、白名单动作、输入资源、输出资源、密码引用、状态、可重跑标识。
- `ConnectorAccount`：连接器、账号标签、会话配置引用、权限能力、过期状态。
- `DebugTrace`：仅 `REPORT_DEBUG_TOOL` 构建标志开启时持久化。Beta 中该开关默认关闭；正式构建可完全编译移除该功能。

数据库为每用户本地 SQLite；凭据仅保留对系统保护存储的引用。

## 状态与故障处理

任务状态：`Draft → Parsing → AwaitingUser → Queued → Downloading → Processing → Completed`，或 `Failed`、`Cancelled`、`Paused`。恢复时从 SQLite 与 aria2 当前状态重新协调。

- 单文件规则解析成功：进入 `Queued` 后立即开始。
- 多文件/目录：在 `AwaitingUser` 停止，用户选择后才排队。
- 登录失效/需要人工验证：保持可恢复的 `AwaitingUser`，打开隔离授权窗口。
- 密码、连接器、解析、下载、后处理失败均带错误分类和可执行的下一步；只在 Debug 选项开启时显示完整链路报告和局部重跑。
- 取消父任务只停止未完成的子任务，不删除已完成或可复用输出；取消子项先检查其是否被后处理依赖。

## 隐私与安全

- 云端 AI 仅在复杂输入时使用，发送当前输入的清洗后可读内容、必要文本附件和处理描述；绝不发送账户、Cookie、token、密码、验证码、二维码、系统文件或已下载文件。
- 外部网页使用受限 WebView2 数据目录和窄能力窗口；第一方应用 UI 的本地命令以 Tauri capabilities 逐项授权。
- 密码显示默认遮盖；仅在用户明确点击时短暂展示。
- 后处理使用任务专属目录，禁止路径穿越、覆盖任意位置或执行未知二进制。

## 可验证的首版能力

1. 可运行的 Windows Tauri 桌面应用，并能在开发模式启动。
2. HTTP/HTTPS、magnet、Thunder 和 `.torrent` 的规则分类；HTTP 单文件可实际加入 aria2 并显示进度。
3. 多文件确认、父子目录任务、暂停/继续/取消和持久化恢复。
4. 复杂文本的本地候选提取，以及可替换、严格校验的 AI 适配层。
5. 夸克/PikPak 的账户连接页面、会话状态、文件管理 UI 与连接器能力/错误状态。真正的服务端操作以用户实际成功授权和服务商允许接口为条件；没有凭据的自动化测试使用受控 mock connector。
6. 安全的归档、分卷、改名和校验计划模型；只有本机安装了兼容归档工具或内置实现可用时执行，否则提示所需条件。
7. Debug 报告功能在 Beta 构建中存在且默认关闭；关闭时不收集详细追踪数据。

## 测试策略

- Rust 单元测试：链接分类、任务状态机、策略拒绝、路径安全、凭据脱敏和处理计划。
- Rust 集成测试：本地 HTTP 服务器 + aria2（可用时）、SQLite 恢复、模拟目录下载。
- 前端测试：输入/确认/父子队列状态/错误反馈和设置开关。
- 连接器契约测试：mock 夸克/PikPak 适配器覆盖登录失效、目录、操作成功/失败和能力缺失。
- Windows 手工冒烟：Tauri 启动、WebView2 授权窗口隔离、系统浏览器回退、真实账户由用户在 UI 中授权。

## 交付拆分

1. 基座：Tauri 壳、任务数据库、下载队列、HTTP/BT/Thunder、浮窗与主界面。
2. 解析：规则解析、确认树、AI 边界、持久化与安全策略。
3. 网盘：夸克/PikPak 账户、会话、连接器契约、自绘文件管理与上传下载。
4. 后处理与调试：受限处理执行、递归发现、可选报告、验证与 Windows 打包。
