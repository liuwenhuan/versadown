# 天翼云盘下线与本机数据清理设计

## 目标

暂时下线天翼云盘：不在网盘管理中展示、不再解析 `cloud.189.cn` 分享链接，并清理本机由应用保存的天翼授权资料、任务资料及可确认归属的下载文件。

## 边界

- 天翼链接必须被识别为不支持的网盘分享链接，不能退化为普通 HTTP 直链任务。
- 保留连接器源码与 `CloudProvider::Tianyi` 枚举，保证旧序列化值仍可被安全读取；运行时目录、分享解析和 API 入口均将天翼视为不可用。
- 首次启动时，在下载引擎初始化前执行幂等清理：清除天翼会话、密码凭据、授权维护记录、网页登录资料、分享计划、普通网盘任务与目录下载任务。
- 只删除任务文件记录和目录成员记录明确指向的绝对路径文件，以及对应 `.aria2` 文件；不得递归删除下载根目录，也不得删除相邻或归属不明的文件。
- 若任一待删除路径不安全、不可读或无法确认归属，保留该任务记录和相关授权资料，供下次启动重试；不得删除其他服务商的数据。

## 清理顺序

1. 从所有任务和目录任务中收集天翼任务，预检每一条可删除的本地路径。
2. 删除已通过预检的任务文件与 `.aria2` 旁路文件。
3. 删除对应任务记录、目录任务记录及天翼分享计划。
4. 清除天翼的所有凭据键、浏览器授权资料和授权状态。

任务文件删除先于数据库记录删除，确保文件路径失败不会让用户失去可重试的记录。清理以天翼的稳定来源前缀或目录任务 `provider` 字段为唯一依据。

## 验证

- 服务商目录中不再包含天翼，天翼链接在输入扫描和分享候选提取中均不产生任务。
- 使用临时任务库和文件系统验证：天翼文件、任务、目录任务、会话资料被清除；百度任务和文件保留。
- 验证不安全或不明确的路径阻止本次清理，不删除数据库记录。
- 运行相关 Rust 测试、前端定向测试、`pnpm run build` 与 `scripts/build-windows.ps1`。
