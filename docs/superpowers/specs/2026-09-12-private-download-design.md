# 私密下载设计

## 目标

在不加密下载文件和目录的前提下，让用户把下载任务标记为私密任务，并在本次应用进程内以密码控制其可见性。

## 行为

- 设置页提供“开启隐私下载”开关和设置/更改隐私密码入口。密码不进入 `settings.json`，而是经现有 Windows DPAPI 凭据存储保存。
- 开关开启后，所有下载入口都先停在确认界面；确认界面同时提供普通“立即下载”和“隐私下载”。后者持久化 `is_private=true`。
- 应用启动时私密任务保持锁定。标题栏任务工具区提供锁按钮；解锁须验证密码，成功只保留到本次应用进程结束。再次点击立即重新锁定。
- 锁定时私密任务不从任务列表、计数、搜索、批量操作或任务更新事件中显示。解锁后，筛选器提供“全部任务”“仅隐私任务”“仅普通任务”；未选择筛选即为全部。
- 云盘目录下载的合成根与其成员继承同一私密标记，避免根目录或子项泄漏私密任务名称。
- 本期不加密已下载文件、目录或数据库中的下载路径；界面和状态隐藏是唯一的隐私边界。

## 数据与安全

- `tasks.is_private`、`cloud_directory_groups.is_private` 均为非空整数，默认 `0`；迁移保证旧任务仍是普通任务。
- Rust 保持解锁会话状态，所有列表、事件与私密任务操作在锁定时拒绝或过滤。
- 设置只保存是否启用和是否已设置密码；密码字节在保存/校验后归零。

## 验收

1. 开启隐私下载但未设置密码会被拒绝；密码不会序列化到设置 JSON。
2. 私密确认会持久化私密任务，重启后仍为私密且默认隐藏。
3. 正确密码解锁可见，错误密码不改变锁定状态；再次加锁后立即隐藏。
4. 已解锁时筛选分别只呈现私密、普通或全部任务；不新增按任务类别排序。
5. 普通下载原有确认与提交流程保持可用。
