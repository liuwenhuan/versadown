# 下载任务节点指标设计

## 目标

在“下载中”列表里，为磁链、BT 种子和 ED2K 任务在任务名同一行的右侧提供引擎实时节点指标。

## 显示规则

- 仅当任务状态为 `downloading` 时显示指标。
- 磁链与 BT 显示 `已连接 x / 已发现 y`：`x` 来自 aria2 的实时 `connections`；`y` 是当前 aria2 进程会话中，通过 `aria2.getPeers` 实际观察到的去重 BT 节点数。
- ED2K 显示 `已连接 x`：当前引擎 RPC 未提供可用于统计逐节点传输或发现数的 ED2K 节点明细。
- 其他协议、暂停、排队、完成和失败任务不显示节点指标。
- 任务标题继续优先省略；节点指标在标题行右对齐，不与操作按钮或进度行重叠。

## 数据边界

- 不将节点 IP、端口或 peer ID 写入数据库、事件或前端；服务层仅在内存里用 `ip:port` 去重。
- `discovered_nodes` 是一个可渲染的计数快照。aria2 重启后，下次成功的节点查询以该会话当前节点集重新开始计数。
- 节点查询失败不得影响下载状态、速度或错误状态的正常同步；仅保留上一次成功的发现数。

## 同步方式

状态协调循环继续读取 `aria2.tellStatus`。当已同步任务是下载中的 `magnet` 或 `torrent`，服务额外调用 `aria2.getPeers`，将本轮节点合入该任务的内存集合，并在计数变化时发布新的任务快照。
