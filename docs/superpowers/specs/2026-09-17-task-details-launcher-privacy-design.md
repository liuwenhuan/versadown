# 任务详情、悬浮弹窗与隐私转换设计

## 目标

让任务详情窗口、悬浮窗和隐私任务转换在所有主题与任务标签页中行为一致：详情窗口只滚动文件树，悬浮图标不因弹窗而重绘，已存在任务可即时切换普通/隐私状态。

## 范围与约束

- 任务详情窗口高度与新建任务窗口相同：`min(520px, calc(100vh - 36px))`。
- 打开任务详情时，主窗口搜索输入框必须禁用并复用既有灰色禁用样式；关闭后恢复可用。
- 文件树显示任务根节点的直接子文件和目录；更深层目录默认收起，用户逐级展开。
- 仅文件树拥有纵向滚动条。标题、任务名称、摘要、来源、后处理信息和安全说明保持在详情窗口非滚动区域内。
- 详情、确认、新建、删除、重复、本地上传、云盘和隐私解锁弹窗必须通过主题变量获得面板、遮罩与阴影颜色；不保留固定蓝色确认图标渐变。
- `launcher` 图标窗口始终为 64x64，位置与六边形窗口区域在左键/右键弹窗前后不变。
- 打开隐私下载后，所有任务标签页的任务右键菜单都可将普通任务移入隐私下载、将隐私任务移入正常下载。
- 隐私转换必须在持久化层和前端可见性层即时生效，且不会在隐私锁定时通过事件泄露私密任务名称或路径。

## 任务详情窗口

`App` 以 `detailsTask` 是否存在作为任务详情的模态状态，并将全局搜索 textarea 的 `disabled` 条件扩展为 `newDownloadOpen || Boolean(detailsTask)`。

`TaskDetailsDialog` 保留固定标题栏，内容区域改为无滚动的网格容器。`TaskDetails` 以纵向网格组织：任务名称、摘要、来源、可选后处理说明、文件树和安全说明。文件树使用 `minmax(0, 1fr)` 占用余下高度并在其列表节点上设置 `overflow-y: auto`；详情窗口内容容器不设置纵向滚动。

任务文件从 `QueueTask.children`（存在时）或扁平 `QueueTask.files` 构造只读目录树。路径拆分同时支持 `/` 和 `\\`，去除与根任务同名的公共前缀。根任务已由详情标题代表，因此初始只渲染顶层目录/文件；每个目录使用独立展开状态。行视觉复用任务列表的展开箭头、目录图标、缩进、文件数和字节信息，但不复用携带暂停/删除/选择命令的 `QueueTreeRows`。

## 主题化弹窗

在主题变量中定义 `--modal-scrim` 和 `--modal-shadow`，替换各模态遮罩与阴影的固定 `rgba` 值。保留按钮白色文字等有意的对比色。确认下载图标由主题 `--accent` 与 `--accent-hover`（或对应 `color-mix`）构成，避免始终显示蓝色。任务详情标题栏、关闭按钮、边框和文件树分隔线均使用现有主题变量。

## 悬浮窗窗口职责分离

继续使用 `launcher` 作为固定 64x64、透明、置顶、无任务栏的图标窗口。新增独立 `launcher-popup` 原生窗口，负责显示左键下载输入面板或右键菜单。原生层从 launcher 的位置、尺寸、当前显示器工作区和 popup 尺寸计算弹窗边界：常规情况下靠右并显示在图标上方；若上方空间不足则显示在下方；所有位置均限制在工作区内。

点击图标只显示或移动 `launcher-popup`，不会调整 `launcher` 的尺寸、形状或位置。关闭菜单/面板仅隐藏 popup。popup 内部通过事件接收 `input` 或 `menu` 模式；其 React 根节点只渲染当前模式的输入面板或上下文菜单。原有 `set_launcher_bounds` 不再用于左键、右键打开/关闭流程。

## 隐私任务转换

前端增加 `move_to_private` 与 `move_to_normal` 任务命令，并将 `privacyEnabled` 传入 `DownloadQueue`。开启隐私下载后，单项任务菜单根据 `is_private` / `isPrivate` 显示对应转换项。多选上下文菜单中，存在普通任务时显示“移入隐私下载”并只转换普通任务；存在隐私任务时显示“移入正常下载”并只转换隐私任务。

新增独立 Tauri 命令 `set_task_private(task_id, is_private)` 与前端 `setTaskPrivacy(taskId, isPrivate)` API；不得把它混入 aria2 的 pause/resume/cancel 命令。普通任务调用现有 store `set_private`。云盘目录组调用新的事务性 store 操作，同时更新目录组及已关联任务的 `is_private` 字段；将来派发的目录成员继续继承组状态。

普通转隐私需要确认隐私下载已启用。隐私转普通需要隐私访问权限。命令返回更新后的任务投影，前端立即 `recordTaskEvent` 和 `upsertTask`。当隐私模式锁定时，普通转隐私后的任务由现有 `privacyVisibleTasks` 过滤立刻从所有标签页移除，同时清除该任务的选择和详情状态；事件发布遵守现有私密事件过滤规则，不发送私密内容。

## 验证策略

- `App.test.tsx`：详情打开时搜索框禁用，关闭后恢复。
- `TaskDetails.test.tsx`：多级路径初态只显示顶层、点击后逐级显示，以及文件树滚动容器语义。
- `TaskDetailsDialog.test.tsx`：固定高度与只有文件区滚动的布局契约。
- `DownloadQueue.test.tsx`：隐私功能关闭时不显示转换项；开启后在四种任务状态、普通/隐私及混合多选状态显示正确菜单项。
- `App.live.test.tsx`：Tauri API 转换后的即时可见性、锁定时隐藏、解锁/筛选时的正常转换。
- Rust：store 的单任务与云盘目录组原子更新；commands 的启用/解锁权限、更新投影和私密事件过滤。
- launcher 前端与 Rust 定向测试：左/右操作不调整图标窗口，popup 位置按上方/下方及工作区夹取计算。
