# 全局带宽限速设计

## 目标

在“设置 / 网络”提供整体下载、P2P 上传与网盘上传三类带宽上限。整体下载默认不限速；P2P 上传默认 1 MiB/s；网盘上传默认不限速。

## 生效规则

- 数值以 MiB/s 输入与展示，后端持久化为字节/秒；`0` 始终表示不限制。
- Aria2 Next 使用 `max-overall-download-limit` 约束其全部下载，并使用 `max-overall-upload-limit` 约束 BT、磁链及 ED2K 的 P2P 上传。
- 自实现 FTP 下载和不经 Aria2 的网盘 HTTP 传输通过共享令牌桶领取下载/上传配额，所有同方向任务共享上限。
- 第一个网盘上传开始时，将 Aria2 的有效 P2P 上传上限改为 1 KiB/s；最后一个网盘上传以成功、失败或取消结束时恢复用户保存的 P2P 上限。更新设置期间维持近零有效上限，但恢复时使用最新保存值。

## 可靠性

上传会话使用 RAII 注册；注册释放必须覆盖成功、错误、取消与 panic 展开。协调器中的并发计数不得为负；只有零到一和一到零的边界请求 Aria2。引擎不可用时不阻断网盘上传，后续重启使用保存的用户上限。

## 验证

Rust：模型默认值/校验、令牌桶和上传协调器边界测试；前端：网络设置输入、保存 payload 与默认值测试；最后执行 Windows 发布构建。不会运行无关全量测试。
